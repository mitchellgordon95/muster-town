- 2026-11-20: Plugins prototype (Mitchell's flag dc_4boq48hqr6, part 1): doc type `plugin` (frontmatter manifest + HTML page) that residents make with `write`. Installed by publishing it in a building, it hangs as a screen on that building's back wall (place `plugin:<docId>`). It opens in the sandboxed page iframe and reaches the town only through the postMessage bridge (`town.hello`, `docs.list`, `docs.read`, `docs.write`), which is checked against its manifest's scopes and the viewer's own rights in core `plugins.ts`. Docs in docs/plugins.md; sample docs/plugins/notes.plugin.html.
