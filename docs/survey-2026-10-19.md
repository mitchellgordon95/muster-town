# Prior art survey — 2026-10-19

Two research passes run on 2026-10-19 (stars and dates from GitHub API that day). Items marked [unverified] rest on abstracts or secondary coverage.

Part 1: pixel-office agent visualizers ("walk around a 2D office, see what each agent is doing, talk to it").
Part 2: research swarms with a shared wiki, and public multi-agent spaces.
Part 3: collectives where many tenants contribute agents or compute toward one headline goal.

### Best to fork or borrow from
1. **Agent Town (geezerrrr)** for the walk-and-talk UX: Phaser 3 + Tiled, player avatar, proximity E, task queue states, streaming tool-call bubbles, typed event bus. The OpenClaw binding sits behind a WS proxy, so swapping in a Claude Agent SDK adapter is tractable.
2. **Pixel Agents** for the agent-state model and binding layer (hooks + JSONL fallback, subagent linking, pathfinding, layout editor). No avatar, no chat, but the most battle-tested Claude Code event pipeline.
3. **SkyOffice** for the multiplayer skeleton (Colyseus rooms, proximity interaction, sit-at-desk) when multiple humans need to walk around together.

Honourable mention: oleg-kalistratov's mod has the cleanest "talk to an agent" path (messages injected into the live session as prompts).

## Part 2 — Research swarms and agent-maintained wikis

### Systems
1. **Karpathy LLM Wiki pattern** (gist.github.com/karpathy/442a6bf555914893e9891c11519de94f, Apr 2026). Immutable raw/, LLM-owned wiki/, schema file. Ops: ingest (one source touches 10-15 pages, append log.md, update index.md), query (answers filed back as pages), lint (contradictions, stale claims, orphans). Follow-ons collected at github.com/gavischneider/awesome-llm-wiki: rohitg00 "LLM Wiki v2" (confidence decay, multi-tier consolidation), ahumanft "V3 Segmentation" (Ingestor / Librarian / Linter roles).
2. **hyperresearch** (github.com/jordan-gibbs/hyperresearch, MIT, Python, ~3.9k★, active Sep 2026). 16-step research pipeline for Claude Code/Codex writing into a markdown vault (frontmatter + rebuildable SQLite index). Per-run isolated workspaces; note lifecycle draft → review → evergreen → stale → deprecated; `dedup` command; provenance tree via `--suggested-by`; contradiction graph; "what source would overturn this?" step; budget cap per run. Closest existing thing to our wiki layer.
3. **Stanford STORM / Co-STORM** (github.com/stanford-oval/storm, MIT, 31.7k★, dormant since Jan 2025). Multiple LLM experts plus a Moderator that asks questions not yet raised; shared hierarchical mind map; human can inject utterances.
4. **Kosmos / Edison Scientific** (arxiv 2511.02824; closed, $200/run). Data agent + literature agent share a structured world model keeping ~200 rollouts coherent toward one objective; every claim traces to code or a passage. 79.4% conclusion accuracy, self-reported [2026 status unverified].
5. **Google Co-Scientist** (Nature May 2026; closed). Generate / Reflect / Rank (tournament) / Evolve / Proximity (clusters hypotheses for diversity) / Meta-review.
6. **Sakana AI Scientist v2** (github.com/SakanaAI/AI-Scientist-v2, 7.4k★, non-OSI licence). Best-first tree search with explicit root diversity. ML-experiment oriented.
7. **Karpathy autoresearch** (github.com/karpathy/autoresearch). Single agent keep/revert on a metric; "program.md as standing orders".
8. **ArcticSwarm** (arxiv 2609.01870, Sep 2026; code unverified). Parallel research agents converge early when they read each other's partial findings. Fixes: shared bulletin board, "gated isolation" (some workers keep restricted peer reads), structured review at three commitment boundaries. Ablations: 82.6 vs 78.8 vs 74.5 on BrowseComp-Plus.
9. **Anthropic multi-agent research system** (anthropic.com/engineering/multi-agent-research-system, Jun 2025). Lead + parallel subagents; lead writes plan to memory; separate citation agent; ~15x token cost of single agent.
10. **AI Village** (theaidigest.org/village; dataset HF aidigestorg/ai-village; scaffolding not open). 30+ frontier agents, own Linux boxes, one group chat, per-agent memory consolidated every 40 actions, weekly goal. Key failure: a hallucinated contact list spread to every agent via sycophantic agreement, costing 8+ hours.
11. **Moltbook / OpenClaw** (Meta acquired Mar 2026; OpenClaw open source). Agent-only social network, ~1.4M agents, humans watch only; cooperative task success ~6.7% [unverified]. **ClawdLab** (arxiv 2602.19810, bio-xyz) is the research-oriented response: hard role restrictions, PI-led governance, adversarial critique, evidence verified by tools not consensus. **Claw AI Lab** (arxiv 2605.22662) is a separate prompt-to-lab platform.
12. **AgentPanel** (arxiv 2608.03283, agentpanel.cc). Async forum where heterogeneous agents discuss a question; humans post questions and organize ideas.
13. **Valhalla** (arxiv 2608.15193, no code). File-Resource-Entity-Relationship-Graph layers; every LLM write mediated so provenance and interpretation stay separate.
14. **ssp.sh "company brain"** (ssp.sh/blog/from-obsidian-to-enterprise-company-brain; demo ssp-data/company-brain-crm). Each agent writes on its own git branch, merges like PRs, typed schema, `DivergentUpdate` conflicts block for human review, actor recorded per write.
15. **Astucia Wiki** (github.com/madsrg/astucia-wiki [unverified]). Flat-file git wiki with MCP server, scheduled agent jobs, per-page chat.
16. **agent-swarm.dev** (github.com/desplega-ai/agent-swarm, MIT, ~900★). Lead/worker in Docker, shared vector memory, recurring tasks. Coding-oriented.
17. **Climate-specific.** ClimateGPT-3-8B (Erasmus.AI, Apache-2.0, Jan 2026) is a model, not an agent system. ClimAgent (arxiv 2604.16922) withdrawn. **No carbon-cycle agent project found.**

Also: Elicit, Consensus, Undermind (closed SaaS; MCP servers usable as desk tools). A2A v1.0 agent cards (`/.well-known/agent-card.json`) are the practical discovery mechanism. Cautionary tale: github.com/swarm-ai-research/wiki-agent-swarm-incident documents benchmark agents turning writable public wikis into a shared answer board (14.6k revisions); an edit-volume monitor caught it 3 days before humans did.

### Design lessons
1. **Isolate before you share.** Desks research with restricted reads of each other's drafts; findings reach the shared wiki through a review gate (ArcticSwarm, Village contact-list cascade). *Our report gate is this.*
2. **Wiki is the substrate, chat is ephemeral.** Markdown + git, index, append-only log, claim pages with status (draft/review/evergreen/stale) and confidence; a scheduled Linter agent for contradictions and orphans.
3. **Dedup at the claim level, not the page level.** Cluster new claims against existing ones before writing.
4. **Every claim carries provenance** (URL/DOI, quote, extracting agent, date). No evidence, no merge.
5. **A Moderator picks directions**: maintains the open-questions page, ranks by coverage gaps and "what would overturn this," assigns to desks.
6. **Humans steer through the wiki and a forum**, not by DMing an orchestrator.
7. **Outside agents get a branch, a schema, and a reviewer.** Conflicts block for human review; actor recorded per commit; edit-volume monitors from day one.
8. **Budget per desk and per run**; expect ~15x single-agent token cost.

### Suggested desk split for the carbon cycle (anchor sources)
- **Atmospheric CO2 and growth rate**: NOAA GML trends (gml.noaa.gov/ccgg/trends), OCO-2/3; GCB 2025 growth rate 2024 = 3.73 ppm.
- **Fossil and cement emissions**: Global Carbon Budget 2025 (Friedlingstein et al., ESSD 18, doi 10.5194/essd-18-3211-2026; data doi 10.18160/GCP-2025), EDGAR, IEA.
- **Land-use change and terrestrial sink**: GCB land section (TRENDY DGVMs), IPCC AR6 WG1 Ch5 (Canadell et al. 2021), FLUXNET/AmeriFlux.
- **Ocean uptake**: SOCAT (socat.info), GOBM ensemble in GCB, RECCAP2 ocean chapters.
- **Soil and permafrost carbon**: SoilGrids / HWSD, Hugelius et al. permafrost inventory, RECCAP2 land regions. *(Not a separate desk in v0; folded into land and feedbacks.)*
- **Feedbacks and budget imbalance**: AR6 WG1 Ch5 feedbacks, C4MIP (Arora et al. 2020), GCB 2025 "unusually large negative imbalance" for 2024.
- Shared cross-desk page: "Where do the methods disagree?" seeded from GCB's own stated disagreements.

## Part 3 — Multi-tenant collectives toward one headline goal

**Short answer: nothing exists yet that is "Folding@home with LLM agents" for climate, disease, or any single open-science goal.** No project combines public tenancy (bring your own agent or compute), one shared goal, alignment enforcement, and a credit scheme.

Nearest neighbors (each has about 2 of the 4 properties):
1. **Agora** (arxiv 2609.18094, Sep 2026; no code). 13 LLM workers across 15 accounts worked ~12 days on one fixed goal with no central planner. Every contribution is a commit in an append-only git DAG. Alignment: a single evaluator metric plus diversity-aware recommendations steering workers to neglected branches. Credit: the DAG (best method's ancestry spans 145 commits by 15 accounts; 165 cross-account verifications). Closest shape to what we want; closed experiment.
2. **Beach.science / ClawdLab** (arxiv 2602.19810). Public research commons where heterogeneous OpenClaw agents post ideas and run analyses "without prior membership in a common laboratory." Role templates and quality thresholds; PI-led governance. Credit and registration [unverified]. Prototype.
3. **Bio Protocol / BioAgents** (bio.xyz). DAO-funded agent fleet per disease area; "Gaia" scoring rubric (Delivery, Transparency, Momentum, Stewardship, Legitimacy, Impact) [unverified]; credit via tokens. Crypto-native, closed agents.

Adjacent lineages (tenancy + credit, but compute rather than research agents):
- **Prime Intellect**: permissionless GPU contributions with TOPLOC verification; Environments Hub crowdsourced via bounties with a separate vetted repo. Lessons: verify contributions by re-execution; separate "submitted" from "verified" pools.
- **Nous Psyche**: Solana-coordinated distributed training [rewards unverified].
- **BOINC / Folding@home**: per-work-unit points, team leaderboards. Nobody has ported this to LLM agents.

Shared workspaces where you bring your own agent, but no shared goal:
- **Block Buzz** (github.com/block/buzz, Apache-2.0, Jul 2026). Nostr-based; each human and agent holds a keypair, so identity and track record are portable across relays. Supports Claude Code, Codex, goose via Agent Client Protocol. Good substrate for public rooms: portable identity solves attribution cheaply.
- **Moltbook**: 1M+ tenant agents, no goal, humans watch only.

### Implications for a public carbon-cycle commons
- Tenancy via portable keys (Nostr/Buzz) or A2A agent cards, not platform accounts.
- Alignment via a published rubric per desk plus a "neglected branches" recommender so new tenants don't pile onto the leaders.
- Credit via the commit DAG: every wiki claim records author, verifier, and ancestry; leaderboard counts verified claims and cross-account verifications.
- Keep a vetted pool separate from a submitted pool.
